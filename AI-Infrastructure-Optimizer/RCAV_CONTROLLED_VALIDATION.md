## 핵심 결론

## 정확도–비용 Pareto 관계

동일 모델·데이터 안에서 정확도 최대, 답변율 비감소, CPU 또는 검증 벽시계 최소의 관측4점을 계산했다. Pareto에 남는 것과 사전 품질 보존 성공은 다르다.

| 모델 | 데이터 | 관측 frontier (CPU·시간 축에서 동일) |
|---|---|---|
| qwen2.5:1.5b | replay150 | RCAV, Improved RCAV |
| qwen2.5:1.5b | fresh300 | RCAV, Improved RCAV |
| qwen2.5:0.5b | replay150 | Selective, RCAV |
| qwen2.5:0.5b | fresh300 | RCAV |

0.5B 신규에서는 원래RCAV가 Improved와 같은 정확도로 더 적은 검증 비용을 썼다.1.5B에서는 Improved가 조금 더 높은 정확도에 추가 비용을 지불하는 trade-off였다. 모집단 전역Pareto 또는 불확실성을 반영한 최적점이라고 해석하지 않는다.

## 오류 위험 예측

동일 최초 답에 대해 RCAV와 Improved의 기본 위험 추정은 같다. 위험 Brier/ECE와p≥0.5 분류 정확도를 원본·비도구 기준으로 별도 저장했다.1.5B 신규 비도구 Brier0.2922, ECE0.1978로 기존 보정의 분포 이동 문제가 드러났다. 단순 호출 생략이 작동했다는 것과 위험 예측이 정확했다는 것은 다르다.

## 시간 telemetry 무결성

검증9건의 서버 prefill/generation이 서버전체시간과 모순돼4개 집계 셀의 모델 처리 시간을 신뢰 가능한 값으로 보고하지 않았다. 원본 CSV와 평균을 보존하고 별도 reporting_summary.csv에서 validated_model_processing_seconds_mean을 비워 표시했다. 자체 벽시계·CPU·토큰 수와 모순된 서버 duration을 섞어 절감 근거로 사용하지 않았다. 원인은 미확인이다.

## 데이터·반복·시연의 한계

서로 다른 새300문제지만 지식은 원자번호·각기둥·논리게이트에 편중됐고 합성 논리/지문·코드 출력 예측이다. 실제 서비스 분포, 자유 서술 품질, 다국어, 긴 문맥, 다른 모델 계열은 검증하지 않았다. 기존150은 이전 연구에서 확인한 개발 자료다.

최초900개 결과에는 두 모델이 같은450문제를 푼 결과와 산술 도구180개가 포함된다. 반복·방법별18,000행을 독립18,000문제로 취급하지 않았다. 모든 생성/검증은 로컬에서 실제 실행했고 모의 출력은 임시 테스트에만 사용했다.

최대 메모리의 연속 실측, 전력, GPU 연산량, 금전 비용은 미측정이다. 그 값을 추정하거나 실제 절감률처럼 표현하지 않았다. 로딩/워밍업·보정은 별도 기록했고 최초 비용 상각도 가정하지 않았다.

기존311개 파일 해시 유지, 과거1522개 질문키와 신규300중복0, 최초 생성 재실행0, API오류0을 확인했다. 프로필·답변 캐시·스케줄·전체 검증 프롬프트와 점수/집계를 재구성했다. 자동 테스트180개를 실행해 통과했다.
