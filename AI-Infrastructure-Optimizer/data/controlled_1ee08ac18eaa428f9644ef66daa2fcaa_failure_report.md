## 실제 정답 손실

1.5B 기존150에서 RCAV는 Selective보다 총정답이3개 많았지만, 기존 정답11개를 잃고14개를 새로 맞혔다. Improved는 총정답이6개 많았지만7개를 잃고13개를 새로 맞혔다. 평균 정확도가 높아도 모든 요청의 정답 보존을 보장하지 않는다.

0.5B 기존150은 RCAV와 Improved 모두 Selective보다 정답이2개 적어, 점추정만으로도 사전 허용 손실1%p를 넘었다. 신규300은 총정답 수가 같았지만 서로 다른 문항의 수정·악화가 상쇄돼 정답 손실 위험이 없다고 할 수 없다.

전체 실패 문항과 실제 최초 답·검증 답·판단 근거·호출ID는 [controlled_1ee08ac18eaa428f9644ef66daa2fcaa_failure_cases.csv](controlled_1ee08ac18eaa428f9644ef66daa2fcaa_failure_cases.csv)에 보존했다. 같은 최초 답을 썼으므로 최초 생성의 차이로 이 손실을 설명하지 않았다.

## 위험 예측의 분포 이동

## 서버 시간 telemetry 불일치

검증 API9건에서 서버 prefill+generation 합계가 서버 total_duration보다 컸다. 예를 들어 prefill898.335초, generation0.032초인데 서버total0.428초, 클라이언트elapsed0.432초였다. 계산 시간을 실측으로 해석할 수 없는 내부 모순이며 원인은 이번 실험에서 확인하지 못했다.

원본 값·원본 평균은 보존했다. 값을 재스케일하거나 유리한 호출만 빼고 재실험하지 않았다. reporting_summary.csv의 validated_model_processing_seconds_mean은 영향을 받은4개 셀에서 미측정/신뢰 불가로 남겼다. aggregate.csv의 model-duration 필드는 원시 서버 보고치이므로 그 상태로 비용 비교에 쓰면 안 된다.

| 모델 | 데이터 | 방식 | 불일치 호출 수 |
|---|---|---|---:|
| qwen2.5:1.5b | fresh300 | Baseline | 4 |
| qwen2.5:1.5b | fresh300 | Selective | 1 |
| qwen2.5:0.5b | fresh300 | Baseline | 3 |
| qwen2.5:0.5b | replay150 | Baseline | 1 |

이 문제는 별도 클라이언트 벽시계, ps CPU 카운터, 호출 수·서버 토큰 카운트와 구분했다. 이들 값도 관측 한계가 있지만, 모순된 모델 duration을 대신 채우거나 GPU 작업량으로 변환하지 않았다.

## 캐시·순서와 독립성 한계

반복 시작의 모델 unload는10/10회 서버 상태로 관측했다. 그러나 반복 안의 prefix-cache 적중 토큰 수, OS/GPU 캐시는 미측정이다. 네 위치 모두에서 RCAV/Improved의 Selective 대비 CPU·시간 차이는 음수였지만, 절감 폭과 반복 시간은 크게 달랐다. 이를 고정된 알고리즘 속도 배수로 주장하지 않는다.

최초 출력은 모델별 문제당1개뿐이고 검증은 seed42로 반복했다.900개 최초 해결 결과에는 두 모델이 같은450문제를 푼 결과와 도구180개가 포함된다.18,000행을18,000개 독립 문제/출력으로 간주하지 않았다. 모델들도 같은 Qwen 계열이며 다른 아키텍처 일반화를 검증한 것이 아니다.

메모리는100ms RSS 표본 최댓값이며 연속 실제 피크가 아니다. 샘플러의 관측 부하는 추정해 빼지 않았다. CPU는 Ollama와 클라이언트 Python의 관측 프로세스 시간이고 GPU FLOPs·전력·금전 비용은 미측정이다.

신규 지식 문항은 원자번호·각기둥·논리게이트에 치우쳤고, 코드 출력 예측·합성 지문/논리도 포함한다. 신문항 문자열 중복은 없지만 의미·템플릿 독립이나 실제 기업 요청 분포를 보장하지 않는다.

## 외부 시연 판단

공정 비교와 실패를 공개하는 연구 프로토타입 시연은 가능하다. 품질을 보장하면서 계산 비용을 줄이는 검증된 상용 제품이라는 시연은 근거가 부족하다. 시간 telemetry 불일치, 위험 보정의 분포 이동, 정확도 비열등성, 다른 하드웨어/부하/모델 계열 검증이 남았다.
