## 변경 범위와 누출 방지

생성(coverage_runner), 검증(request_verifier), 선택(coverage_policy)을 분리했습니다. 20표본·Wilson 하한 80%라는 작은 모델 기준을 유지하고, 보정 프로필은 한 번만 읽어 메모리에 고정했습니다.

신뢰도가 낮은 요청은 1.5B를 검증 대상 후보로 호출합니다. 산술식에 한해 입력 식을 계산해 모델 출력과 비교하는 **결정적 산술 검증기**를 추가했습니다. 이 기능은 평가 정답을 읽지 않지만 실행 중 입력 식의 올바른 값을 계산합니다. 따라서 순수 LLM 신뢰도 라우팅과 다른, 도구 검증을 결합한 시스템입니다. 계산값을 답변으로 대신 반환하거나 모델의 프롬프트에 정답·수정값을 제공하지 않습니다. 검증된 모델 응답만 반환합니다.

큰 모델의 사전 신뢰도가 좋아졌다고 가정하지 않습니다. 오류·잘못된 정수·추출 실패 시 1.5B를 최대 한 번 재시도합니다. 단순히 답변 비율을 높이기 위해 실패한 답변을 승인하지 않습니다. 일반 자연어 요청에는 이 검증을 적용할 수 없습니다.

정답 라벨은 모델 선택·생성·실행 함수에 전달하지 않고 모든 모델 호출이 끝난 뒤 채점에만 사용했습니다. 기존 200문제는 명시적인 재평가이며 독립 홀드아웃으로 주장하지 않습니다. 신규 100문제는 기존 CSV·JSON 및 재평가 세트와 교환법칙 중복까지 제외했습니다. 평가 결과에 따라 프롬프트·재시도 예산·기준을 변경하지 않았습니다.
