## 형식과 내용 오류

각 방식의 비산술80문제에는 접두어 없는 단일 문자45건이 있습니다. 그중38건은 정답,7건은 오답입니다. 형식이 맞았던35건 중에도10건은 오답입니다. 따라서 형식만 개선해도 모든 내용 오류가 해결되지는 않습니다. API 장애나 출력 토큰 제한으로 인한 절단과도 구분해야 합니다.

원래 요약의 format_failures 필드는 모델 호출 후 미답변을 합산해 Coverage의 산술 검증 실패7건도 포함했습니다. 새 문항별 감사 CSV는 정책 거절·형식만 오류·형식+내용 오류·내용 오류·검증 실패를 분리합니다.

## 비산술 응답이 같은 이유

비산술80문제 중 네 응답이 모두 같은 문항은 80개입니다. 원래 산술 라우터는 일반 작업을 거절하므로 mixed_runtime의 공통 어댑터가 모든 비산술 요청을 동일한 qwen2.5:1.5b·프롬프트·온도0·출력64토큰 상한으로 보냈습니다. 각 방식에80회, 총320회 모델 시도가 기록됐습니다. 현재 코드는 비산술 모델을 차별적으로 선택하지 않으며 별도 결과 캐시나 앞 방식의 답을 복사하는 경로도 없습니다. 같은 입력/설정이 동일 응답의 직접적인 구조적 이유이며 온도0도 일관성에 기여할 수 있습니다.

실제 HTTP 요청 본문·서버 요청ID·seed·캐시 hit 로그는 저장하지 않았습니다. identity.csv의 요청 해시는 고정된 소스에서 재구성한 값이며 네트워크 캡처를 뜻하지 않습니다. 서버 내부 캐시나 비결정성을 완전히 배제했다고 주장하지 않습니다.
