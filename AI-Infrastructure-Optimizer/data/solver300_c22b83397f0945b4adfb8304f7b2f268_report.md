# 해결 방법 자동 선택: 신규300문제 실제 실험

실행 ID `c22b83397f0945b4adfb8304f7b2f268`.

## 사전에 고정한 정책

- Fixed: 모든 문제에1.5B 한 번.
- Rule: 명확한 정수 산술은 도구, 짧은 지식·지문은0.5B, 그 외는1.5B.
- Confidence: 유형별0.5B 보정 정확도의95% Wilson 하한이0.8 이상이고 최소20표본·쉬운 요청일 때0.5B, 그 외1.5B.
- Hybrid: 산술 도구 + Confidence의 모델 선택. 난이도는 연산·문장길이·코드구조의 휴리스틱이며 정답 라벨이 아니다.
- 작은 모델의 파싱/API 실패만1.5B로 fallback. 잘못된 비산술 내용을 정답을 보고 전환하지 않는다. 큰 모델이 실패하면 원인을 기록하고 중단한다.

기존 혼합100문제 중 모호한 소유권4개를 제외한96개와 명시적 새 보정4개로 두 모델을 실제 보정했다. 평가300개는 보정 및 과거 모든 문제와 선택지 순서/정규화/교환 중복까지 제외했다. 각 유형60개이며 지식은 기초 사실 객관식, 코딩은 출력 예측, 지문·논리는 합성 템플릿이다. 같은 템플릿 계열의 일반화 한계가 있다.

프로필·문제·출력 계약·재시도 예산은 평가 전에 고정했다. 모든 모델 호출에 같은 프롬프트 규칙·온도0·seed42·출력64토큰 상한을 사용했다. 주 정확도는 유일한 최종 답 또는 응답 전체의 단일 문자/정수로 채점하며, 형식 미준수와 해석 불가능 형식 오류를 별도로 기록했다. 이는 이전 엄격한 FINAL_ANSWER 점수와 다른 사전 정의 계약이므로 과거 점수와 직접 비교하지 않는다.

## 무결성·누출·평가 한계

라우터는 질문·전략·고정 보정 통계만 받는다. 기대 정답/유형 라벨/참조 코드는 모델 호출에 전달하지 않는다. 보정 정답은 보정 프로필에만 사용하고 평가 정답은 생성 후 채점에만 사용했다. 과거 MC 문제는 선택지 순서를 제거한 질문 줄기로도 중복 검사했고, 코드60개는 수작업 기준 프로그램의 격리 출력과 선택지를 실행 전에 대조했다. 생성된 모델 코드는 실행하지 않았다. 지식 라벨은 기초 사실 수작업 구성으로 외부 기관의 독립 검증을 뜻하지 않는다.

문항별 실제 유형 추정·난이도·선택 사유·모델 호출 순서·직접 도구·내용오류·fallback을 evaluation.csv에 보존했다. 클라이언트 request_id와 실제 직렬화 본문 해시/요청옵션·입출력 토큰을 기록했지만 서버 내부 캐시 hit와GPU는 측정하지 않았다. 같은 문제 네 방식을 순환 실행해 위치를 균형화했으나 같은 입력의prefix cache 영향을 완전히 제거하지 못했다. 영어 객관식·합성 템플릿·단일 실행이며 자유 코드 생성·장문·외부 검색·상용 서비스 부하의 성능으로 일반화할 수 없다.

원본 소스와 과거 실험 데이터는 해시로 보존을 확인했다. 유료 API와 추가 모델 설치는 사용하지 않았다.
