# VVP 추출 실패 응답의 별도 내용 감사

기존 점수·학습 라벨·선택·성공 판정은 변경하지 않았다. 기존 파서는 응답 전체가 인정 형식에 맞아야 추출하므로 명확한 설명문도 실패할 수 있다. 실제 반환 문장의 모든 미추출 응답 25개를 따로 검사했다. 이는 평가 후 발견한 표현에 대한 **사후 보조 분석**이며 사전 등록 독립 검증 결과가 아니다.

추가 규칙은 정답을 입력받지 않고 단독 `A.` 형태, 선택지 본문과 일치하는 명시적 출력 주장, 목록과 선택지가 서로 일치하는 명시적 결론만 인정한다. 추론 중단이나 상충 주장은 계속 미해결로 둔다. 실제 코드 실행의 fallback 결과를 바꾸지 않고 최종 반환된 원문만 다시 해석했다. 이 제한된 감사가 모든 자연어 의미 오류를 해소한다고 주장하지 않는다.
